# Product and Category Management System

## Project Overview
This project demonstrates a Product and Category Management System using MySQL Workbench. It includes database creation, table creation, data insertion, update and delete operations, SQL reports, and an Entity Relationship (ER) Diagram.

## Database Name
inventory_db

## Features
- Created the database
- Created categories and products tables
- Inserted sample data
- Performed UPDATE operations
- Performed DELETE operations
- Generated Product Catalog Report
- Generated Category Summary Report
- Generated Low Stock Report
- Generated ER Diagram
